# 📊 Sales Dashboard

A modern and responsive Sales Dashboard built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Recharts**. The application provides interactive sales analytics for the years **2022, 2023, and 2024** using realistic mock data.

## 🔗 Repository

GitHub Repository:
https://github.com/Intiyaj-Raj/sales-dashboard

---

## ✨ Features

### Core Features

- Atomic Design Architecture (Atoms, Molecules, Organisms)
- Interactive Sales Dashboard
- Year Selector (2022, 2023, 2024)
- Bar Chart
- Line Chart
- Pie Chart
- Responsive Dashboard Layout
- Statistics Cards
- Top Products Table
- Clean and Modern UI

### Enhancements

- Custom Sales Threshold Filter
- Dynamic Chart Switching
- API-Ready Data Layer
- Responsive Design
- Modular Component Structure
- TypeScript Support

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Intiyaj-Raj/sales-dashboard.git
```

Move into the project

```bash
cd sales-dashboard
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 📦 Production Build

```bash
npm run build
npm start
```
